Fuentes de los modelos 3D propios, generados con SolidCraft (`solidcraft-cli`); `gen.py` produce los tres `.json` (sht4x, pgtdso14 y borne).
Para regenerar un modelo: `solidcraft-cli run X.json --out Y.step`.
Ejes: mm, Z = 0 en la cara superior de la placa, origen = origen de la huella, modelo (x, y) = huella (x, −y); en KiCad, offset 0, rotación 0 y escala 1.
